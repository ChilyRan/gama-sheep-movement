# GAMA Agent based modeling project

- It is a project that we build agent based modeling to model sheep movement.

## Installation

- Download GAMA version 2026-09 from Release and choose the one that appropriate with the OS(With JDK version is recommended.)
- Go to GAMA workspace that has been set.
- `git clone https://github.com/ChilyRan/gama-sheep-movement`
- `cd gama-sheep-movement`
- open the GAMA app
- Run the experiment

## About the project:

- Research questions:
  - How do sheep move around to avoid obstacles?
  - How do sheep find and move toward available grass?
  - How do sheep change their behavior when they encounter a dog and how do they regroup afterward?
  - How do grazing affect the sheep movement between grass areas ?
  - How does grass regrowth affect where sheep move and graze?
